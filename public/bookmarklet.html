Mobile Installation

The easiest way on a phone or tablet is to download the song's ChordPro file from SongSelect, then open it in Import Songs.

To use the bookmarklet anyway, bookmark any page, then edit the bookmark and paste the code from the "Alternative Method" above as its URL. On Android, run it by typing the bookmark's name in the address bar and tapping it.

On iPhone and iPad, songs it imports in Safari don't reach Chordless installed on the home screen, which keeps its own separate storage.

How It Works

  1. Navigate to a song on SongSelect
  2. Click the bookmarklet
  3. It opens Chordless's Import Songs page, and downloads the song's ChordPro file from SongSelect using your login
  4. It sends the song to Chordless, which saves it to your library
  5. Choose a setlist to add it to, or just keep it in the library
