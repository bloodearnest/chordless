Verovio

The lead sheet in Chordless's lead sheet view is engraved by Verovio, version 6.0.1, copyright © Laurent Pugin and others (RISM Digital Center and contributors). It is free software under the GNU Lesser General Public License, version 3 or any later version, which refers to the GNU General Public License, version 3. Both are copied here in full.

  • Source. Verovio's source code, for this version, is at github.com/rism-digital/verovio (version 6.0.1), and the package Chordless uses is verovio 6.0.1 on npm.
  • Unmodified. Chordless uses Verovio as it is released and has not changed it. It is a file of its own, loaded only when a sheet is first shown, and is not mixed into the rest of the app's code, so another build of Verovio can be loaded in its place. To use a modified Verovio with Chordless, or for anything else about this, write to bloodearnest@gmail.com.
  • Music font. The notation glyphs are Leipzig, which is part of Verovio, under the SIL Open Font License 1.1.
